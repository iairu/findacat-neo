## Model hostingu

Web je statická stránka s JSON API v Laraveli pod `/api`. Je navrhnutý pre FTP/cPanel hosting: na serveri nie je potrebný Node.js, SSH ani Composer.

## Plánované kapitoly

- Nahratie vydania a nastavenie `.env`
- Spustenie inštalátora a vytvorenie prvého účtu správcu
- Import databázy z findacat.eu
- Zálohy, import a export CSV
- Správa plemien a farieb EMS
- Schvaľovanie registrácií
