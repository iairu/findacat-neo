API je dostupné pod `/api` na tej istej doméne ako web a používa relácie cez cookies.

## Plánované koncové body

| Oblasť | Účel |
| --- | --- |
| Účty | Registrácia, overenie e-mailu, prihlásenie, obnova hesla |
| Mačky | Hľadanie, čítanie, vytvorenie, úprava, zmazanie |
| Rodokmeň | Predkovia mačky ako dáta pre strom alebo graf |
| Inbreeding | Koeficient mačky alebo dvojice kocúr a mačka |
| Plemená a EMS | Referenčné zoznamy |
