Find A Cat stores cat pedigrees and calculates the **coefficient of inbreeding** (COI) of a cat or of a planned mating.

## Where to start

- **Using the site?** Begin with the [user guide](/docs/guide/).
- **Curious how the numbers are produced?** Read [how inbreeding is calculated](/docs/genetics/inbreeding/).
- **Running your own copy?** See [admin and self-hosting](/docs/admin/).
- **Building on top of it?** The [API reference](/docs/api/) lists the endpoints.

## About the project

Find A Cat began as a thesis project in 2024 and is being rebuilt as a static website with a separate JSON API, so it can run on ordinary shared web hosting.
