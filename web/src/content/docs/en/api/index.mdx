The API is served under `/api` on the same domain as the website and uses cookie-based sessions.

## Planned endpoints

| Area | Purpose |
| --- | --- |
| Accounts | Register, verify email, log in, reset password |
| Cats | Search, read, create, update, delete |
| Pedigree | Ancestors of a cat, as tree or chart data |
| Inbreeding | Coefficient for a cat or for a sire and dam pair |
| Breeds and EMS | Reference lists |
