# Find A Cat

Cat pedigree database with inbreeding (COI) calculations for pedigrees and test matings. A static Astro site (`web/`: homepage, docs, portal) and a Laravel JSON API (`api/`).

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fiairu%2Ffindacat-neo&project-name=findacat&repository-name=findacat&products=%5B%7B%22type%22%3A%22integration%22%2C%22integrationSlug%22%3A%22neon%22%2C%22productSlug%22%3A%22neon%22%2C%22protocol%22%3A%22storage%22%7D%5D)

The button copies the repository to your account, creates a Neon Postgres database and deploys. The build runs the migrations, generates `APP_KEY` and prints a setup link in the build log, where you create the first administrator. See the [Vercel guide](web/src/content/docs/en/admin/vercel.mdx) for mail settings and custom domains, and [installing on shared hosting](web/src/content/docs/en/admin/index.mdx) for FTP/cPanel.
